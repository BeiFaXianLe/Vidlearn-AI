## 0. 一句话结论

方案整体成立。**实测（yt-dlp 2026.10.26，匿名无 Cookie）已确认：B站 1080P 画面 + 音频可拿，但平台字幕/自动字幕都为空**（详见 `docs/evidence/S0_能力实测报告.md`）。因此一期字幕链路默认走 ASR——这与已确认的「本地 faster-whisper 默认 + 云端可选」完全吻合。

已确认的四项决策：① 自建骨架 + 借鉴 MIT 代码；② 平台策略 A+C（默认匿名+本地文件），B 登录态做可选开关、默认关闭；③ ASR 本地优先；④ 按 S0→S8 顺序推进。

推荐路线：**自建 FastAPI + SQLite + React/Vite 骨架，按 PRD 数据模型落地；MIT 项目（BiliSum / BiliNote）只借鉴代码与思路，不整体 fork，不拷贝 GPL 组件（VideoCaptioner、FFmpeg full build）。**
