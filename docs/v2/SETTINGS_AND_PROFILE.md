# 设置：身份认证门户 + 个人职业

> VidLearn AI V2.3 · 把「配置」和「使用」分开

## 为什么把认证独立出来

导入视频是最常用的动作，不该被 Cookie、扫码这些配置项打断。所以：

- **导入弹窗**只保留与「这一次导入」有关的选项（清晰度、后台执行、识别与标点、B站收藏夹）。
- **平台登录态**统一收到「设置 → 身份认证」，一次配好，长期有效。

## 身份认证

左侧「身份认证」分区，B站 / 抖音两个渠道。

每个渠道显示**连接状态点**：绿点=已连接，灰点=未连接。展开后可以：

| 操作 | 说明 |
|---|---|
| 粘贴 Cookie → 保存 | 直接粘贴整段 Cookie 或 SESSDATA，加密存本机（DPAPI） |
| 检测登录 | B站会真实校验并显示用户名；抖音做字段体检（无离线登录接口） |
| 扫码登录 / 从浏览器获取 | 仅抖音：打开一个独立浏览器窗口扫码，再从该浏览器取回登录态 |
| 解除认证 | 清除该渠道的凭据 |

> 不认证也能用。认证主要用于：私密内容、部分高清、B站收藏夹批量导入。

## 个人职业

填好后，**每份 AI 总结会多一段「这对你的职业有什么用」**。

| 字段 | 必填 | 说明 |
|---|---|---|
| 你的职业 | 建议填 | 可自由输入，也可从 16 个常用标签里选（最多 6 个） |
| 所在行业 | 选填 | 例如互联网、教育、医疗 |
| 近期想达成的目标 | 选填 | 一句话，例如「半年内独立负责一个项目」 |

建议会出现在详情页「AI 总结」的核心要点之后，用绿色引用块呈现。

### 生成要求（写进 prompt 的约束）

- **只说字幕里有的**，不编造。
- **说人话**：像同事聊天，不堆术语、不喊口号、不说「提升核心竞争力」这类空话。
- **给动作**：指出视频里哪一点对这个岗位有用、可以怎么用、下一步做什么。
- 100~200 字，2~3 句一段。
- **关联弱就直说**：内容与职业关系不大时如实说明，只给一条最接近的启发，不硬凑。

> 没填职业档案时，总结与以前完全一样（不会出现这一段）。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings/profile` | 读取职业档案 + 可用标签 |
| PUT | `/api/settings/profile` | 保存职业档案 |
| POST | `/api/analysis/summary` | 生成总结（会自动读取职业档案） |

职业档案存在本机 SQLite 的 `app_settings` 表（key = `user_profile`），不上传任何地方。
