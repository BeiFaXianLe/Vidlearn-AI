## 3. 关键样本与命令

### 3.1 B站匿名格式（`yt-dlp --list-formats`）
```
30016 mp4 640x360  350k  avc1
30032 mp4 852x480  787k  avc1
30064 mp4 1280x720 1753k avc1   <- 匿名单流最高
100111/100024    720P  hev1/av01
30280 m4a audio 204k
[警告] 1080P formats are missing; you have to become a premium member
```

### 3.2 下载 + 校验（S0-08 通过）
```
yt-dlp --download-sections "*0-15" -f "30064+30280" --merge-output-format mp4 -o probe.%(ext)s <url>
-> probe.mp4 3.74MB
ffprobe: duration 15.12s / video h264 1280x720 / audio aac
ffmpeg -f null - : decode_exit 0
```

### 3.3 内嵌字幕提取（S0-09 通过）
```
ffprobe -select_streams s -> 1 stream (subrip)
ffmpeg -map 0:s:0 -> extracted.srt 内容与源一致，时间戳 00:00:00,500 起
```

### 3.4 截断文件（S0 测试集通过）
```
ffprobe -> "moov atom not found / Invalid data found"
ffmpeg -f null - -> exit 1
=> 可明确识别失败；但"能识别损坏"不等于"能判定完整性"，S3 仍需尾部解码 + 时长比对
```

### 3.5 本地 ASR 基准
```
faster-whisper small, CPU int8
模型加载 1.6s / 18.5s 音频转写 2.5s / RTF 0.13 / 语言 zh
与人工原文相似度 0.954
```

## 4. 依赖坑（已在 S1 前处理）

| 问题 | 现象 | 处理 |
|---|---|---|
| PyAV 19 与 faster-whisper 1.2.1 不兼容 | `av.open() got an unexpected keyword argument 'metadata_errors'` | **不要依赖 faster-whisper 内置解码**；用 FFmpeg 解出 16k 单声道 PCM，再以 numpy 喂模型（也符合"FFmpeg 为主处理引擎"架构） |
| curl.exe 在本机不可用 | 所有 URL 报 SSL error 35 | 所有网络验证用 Python / yt-dlp，不用 curl |
| Python 3.14 为默认 | 部分 ML 包轮子不全 | 统一用 uv 3.12 虚拟环境 |

## 5. 对方案的影响（已同步到执行清单）

1. **字幕链路默认 ASR**：匿名无字幕，这一条被两个样本 + 抖音验证共同确认。
2. **画质预期下调**：一期匿名下线 720P 为事实上限；1080P 只能在 B 开关（登录态）下提供。产品文案不要承诺 1080P。
3. **抖音不进一期 SLA**：匿名不可用，仅保留 Adapter 占位与明确失败提示。
4. **完整性判定必须多指标**：损坏文件能报错，但部分下载/截断未必报错，S3/S4 需尾部解码 + 时长比对 + 字幕覆盖检查。
5. **许可证**：FFmpeg full build 为 GPL；仅自用无碍，对外分发需换 LGPL。
