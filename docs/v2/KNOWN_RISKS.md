# 已知风险清单（KNOWN_RISKS）

> VidLearn AI V2.0 · S0 结论
> 标注 **[S0 实测]** 的为已验证的风险，非推测。

## 一、高风险

### R1 平台字幕返回错位（S0 实测）
- **现象**：同一 `aid+cid` 连续请求返回 55/138/173 条不等，出现末条 306s、309s 远超视频 106s。
- **影响**：错误字幕 → 错误总结，且用户难察觉。
- **缓解**：时长强校验（`末条 ≤ 时长+2s`）+ 重取 N 次 + 校验失败降级 ASR + 留存原始字幕与来源。

### R2 Cookie / 凭证泄露
- **影响**：账号被他人使用、平台封号。
- **缓解**：DPAPI 加密、明文仅内存、日志脱敏（`SESSDATA`/`ttwid`/`msToken`）、不入仓库、异常栈脱敏。

### R3 平台风控与接口变化（S0 实测）
- **现象**：抖音 `ArgusSecurityPlugin` 403；B站 WBI 签名会变。
- **影响**：下载能力随时失效。
- **缓解**：Adapter 隔离、固定 yt-dlp 版本 + 回归样本、失败明确降级、不承诺全平台。

## 二、中风险

### R4 切片硬切导致文本截断/重复（S0 实测）
- "工作站"→"工作"+"作战"；30s 边界句子重复。
- **缓解**：重叠切片 1–2s + 边界去重 + 时间戳单调校验。

### R5 模型首次加载耗时 600s（S0 实测）
- 用户以为卡死。
- **缓解**：预置模型、加载进度、超时提示、可选小模型默认。

### R6 媒体不完整被误判可用
- 部分截断时 FFprobe 不报错。
- **缓解**：多指标（容器解析+时长比对+完整解码+尾部解码+流存在性），用途感知判定。

### R7 FFmpeg full build 的 GPL 分发
- 对外分发时整包受 GPLv3 约束。
- **缓解**：分发前换 LGPL build 或做合规评估。

### R8 长视频资源占用
- 1h+ 视频的 ASR/解码占用 CPU/内存/磁盘。
- **缓解**：切片、并发限制、资源监控、磁盘配额。
