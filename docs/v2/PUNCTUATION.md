# 字幕标点恢复（ASR Punctuation）

> VidLearn AI V2.0 增强 · 2026-11-02

## 为什么需要

faster-whisper 输出的中文**没有标点**：
```
欢迎收看1124期时间消息
10月6日 日本便利店巨头711发布声明
```
阅读体验差，也不利于后续的章节/知识点生成与检索。

## 方案

用**云端 LLM（DeepSeek）**为字幕补标点，规则严格：

1. **只加标点**，不改字、不增删内容、不合并拆分行
2. 分批发送（40 行/批），要求返回等长数组
3. **逐条校验**：
   - 实义字符（去掉标点/空白后）必须**完全一致** → 否则判定模型改写，丢弃该条
   - 长度比必须在 0.6–1.6 之间 → 异常则丢弃
4. 结果存为**派生字幕轨** `asr_punct`，**原始 `asr` 轨保留**（PRD §5.3：润色不得覆盖原始字幕）

## 数据流

```
ASR 字幕 (asr)
   ↓  LLM 逐批加标点 + 逐条校验
派生字幕轨 (asr_punct)  ← 作为主轨优先展示
   ↓
前端字幕（分段、带标点）
```

主轨优先级：`bilibili_human > bilibili_ai > user > embedded > asr_punct > asr`

## 实测结果（30 分钟视频，971 句）

| 指标 | 值 |
|---|---|
| 成功加标点 | **967 / 971**（4 条因校验不通过被保守丢弃） |
| 耗时 | 约 50s（分批调用） |
| 成本 | 仅发送字幕文本，无音频/视频 |

示例：
```
2016年10月30日 星期五                →  2016年10月30日，星期五。
欢迎收看1124期时间消息                →  欢迎收看1124期时间消息。
10月6日 日本便利店巨头711发布声明      →  10月6日，日本便利店巨头711发布声明，
```

## 使用方式

| 场景 | 操作 |
|---|---|
| 新导入视频 | 导入弹窗勾选「为识别出的字幕自动补标点」（默认开） |
| 已有视频 | 详情页 → 字幕 Tab → 点「补标点」 |

## 接口

| 接口 | 说明 |
|---|---|
| `POST /api/analysis/punctuate` | 提交标点恢复任务，返回 `task_id`（后台执行） |
| `GET /api/tasks/{id}` | 查询进度 |

## 数据边界

只发送**字幕文本**给云端 LLM，不发送视频/音频/关键帧 —— 符合 PRD 冻结的数据边界。

## 依赖

`opencc-python-reimplemented`（繁→简，t2s）与 DeepSeek API Key（`.env`）。
