# VidLearn AI · PoC Acceptance Criteria V2.0

> 版本：V2.0 · 2026-11-02
> 定位：S0 前置门禁的验收标准。**PoC 不通过，对应能力不得标记为正式可用。**

## 0. 通用要求

- 全程记录：环境版本（Python / yt-dlp / FFmpeg / faster-whisper）、命令、返回码、stdout/stderr 摘要
- 不得把「能列出格式」当作「能下载」
- 不得把「extractor 存在」当作「平台全量支持」
- 不得使用未经授权的内容；不得绕过 DRM / 会员 / 验证码 / 反爬
- 结论须可复现：附样本 URL 类型、实际产物、FFprobe 结果

## 1. S0-01 B站 Cookie 登录 PoC

| 项 | 验收标准 |
|---|---|
| Cookie 导入 | 手动粘贴 SESSDATA 等字段，系统完成格式转换 |
| 加密存储 | 经 DPAPI 加密落盘，明文不出现 |
| 解密使用 | 解密后注入请求头，下载成功 |
| 1080P 下载 | 登录态下实际下载到 1080P 并 FFprobe 校验通过 |
| 失效处理 | 无效 Cookie 返回明确 `need_login` 类错误 |
| 日志安全 | 全链路日志与异常堆栈不出现 Cookie 值 |

**通过条件**：以上 6 项全部满足。若 1080P 不可得但 720P 稳定，记为「部分通过」并注明原因。

## 2. S0-02 B站平台字幕 PoC

| 项 | 验收标准 |
|---|---|
| 人工字幕 | 登录态下能获取到字幕列表并可下载 |
| AI 字幕 | 能获取并**标注来源为 AI 生成**，不与人工字幕混淆 |
| 无字幕场景 | 明确返回「无字幕」，触发后续 ASR 流程 |
| 时间戳 | 能转换为毫秒并落在视频有效时长内 |
| 多语言 | 多语种字幕分别保存，不互相覆盖 |

**通过条件**：至少 1 个样本拿到人工字幕 + 1 个样本拿到 AI 字幕；无字幕场景返回明确状态。

## 3. S0-03 抖音下载 PoC（D05，强门禁）

采用 `jiji262/douyin-downloader` 独立子进程。

| 项 | 验收标准 |
|---|---|
| 短链解析 | `v.douyin.com` 短链可解析到视频 |
| 长链解析 | `douyin.com/video/<id>` 可解析 |
| 元数据 | 标题、作者、时长、封面可取 |
| 实际下载 | 下载到真实视频文件 |
| FFprobe 校验 | 文件可解析，含有效音视频流 |
| 匿名模式 | 记录匿名是否可行（**这是 D04 的核心**） |
| Cookie 必要性 | 若匿名不行，记录 Cookie 能否解决、需哪些字段 |
| 依赖与许可证 | 记录依赖项、许可证、运行稳定性 |

**通过条件**：至少一种 URL 形态可完成「解析→下载→FFprobe 通过」。
**门禁**：不通过则抖音能力标记为「预留」，UI 给出明确降级提示，不作为一期验收项。

## 4. S0-04 ASR PoC

| 项 | 验收标准 |
|---|---|
| 音频提取 | FFmpeg 输出 16kHz 单声道 PCM（不经 PyAV） |
| 识别 | faster-whisper 输出带时间戳的分段 |
| 长视频 | ≥30 分钟音频切片处理，无崩溃 |
| 切片合并 | 合并后时间戳连续、偏移正确、无重复文本 |
| 质量 | 与人工字幕抽检对比，记录相似度/字错率 |
| 资源 | 记录 CPU/内存/RTF（实时率） |

**通过条件**：长视频切片 + 合并后时间戳误差在可接受范围；RTF 记录在案。
（参考基线：本机 CPU int8 small 模型 RTF ≈ 0.13，中文相似度 ≈ 0.954）

## 5. S0-05 媒体完整性 PoC

| 项 | 验收标准 |
|---|---|
| 正常文件 | 状态为 `verified` |
| 截断文件 | 能识别（moov 缺失 / 解码失败），状态不为 `verified` |
| 无音轨 / 无视频流 | 分别给出明确原因 |
| 时长比对 | 容器时长 vs 流时长 vs 元数据时长，差值记录 |
| 播放验证 | 尾部可解码到结束 |
| 多指标 | 不得仅凭单一 FFprobe 指标判死 |

**通过条件**：4 类样本（正常/截断/无音轨/异常编码）均给出正确分类与可读原因。

## 7. 门禁总结

| PoC | 级别 | 不通过的后果 |
|---|---|---|
| S0-01 B站登录 | 必需 | B站登录模式不可用，退回匿名 720P |
| S0-02 B站字幕 | 必需 | 字幕全部依赖 ASR，成本与耗时上升 |
| S0-03 抖音 | **强门禁** | 抖音标记「预留」，UI 降级提示 |
| S0-04 ASR | 必需 | 无字幕视频无法处理 |
| S0-05 完整性 | 必需 | 可能把不完整视频标为完整，产生错误总结 |
