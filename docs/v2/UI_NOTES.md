# 前端 UI 说明（对齐原型 V1.1）

> VidLearn AI V2.0 · 2026-11-02
> 原型：[docs/v1/delivery_V1.1/VidLearn_AI_Prototype.html](../v1/delivery_V1.1/VidLearn_AI_Prototype.html)

## 一、详情页结构

```
┌─ 左栏 leftcol ────────────┬─ 右栏 rightcol（吸顶，占满视口高）──┐
│ ┌ 播放器（sticky 吸顶）┐   │ Tab: AI总结 │ 章节与字幕 │ 知识点 │ 说明 │
│ │   <video>           │   │ ┌─────────────────────────────┐ │
│ └──────────────────────┘   │ │ 章节 chip 行（点击跳转）      │ │
│ 学习信息（收藏/原平台/删除） │ │ ┌ 章节块 tsec ───────────┐   │ │
│ 学习笔记（保存/导出Markdown）│ │ │ 标题 + 该章字幕段落     │   │ │
│                            │ │ └────────────────────────┘   │ │
│                            │ │ ┌ 章节块 tsec ───────────┐   │ │
│                            │ │ └────────────────────────┘   │ │
└────────────────────────────┴─ └─────────────────────────────┘ │
```

## 二、关键交互

| 交互 | 行为 |
|---|---|
| **播放器吸顶** | `.leftcol .player{position:sticky;top:16px;z-index:10}` —— 滚动时固定在左上角，不会被划走 |
| **章节与字幕合并** | 原「章节」Tab 与「字幕」Tab 合并为「章节与字幕」 |
| **章节 chip 行** | 横向可换行；点击 → 视频跳转到该章起点 + 平滑滚动到对应字幕块 + chip 高亮 |
| **字幕按章分组** | 字幕按章节时间范围切分到各 `.tsec` 块；块标题可点击跳转 |
| **当前章节高亮** | 播放位置所在章节的 chip 与字幕块自动高亮（`.active`） |
| **字幕随播放高亮** | 当前播放到的字幕段落高亮（蓝色） |

## 三、样式基线（取自原型）

| 元素 | 值 |
|---|---|
| 字幕正文 / 章节字幕段 | 14px / line-height 2 |
| AI 总结导语 | 14px / line-height 1.8 |
| 总结要点、列表项 | 14px / #5b6880 / line-height 1.85 |
| 小节标题 h4 | 14.5px |
| Tab | 13px |
| 时间戳 | 12px 等宽 |
| 章节标题 b | 13.5px |
| 面板内边距 | 18px 20px |
| 左右栏比例 | 1.25fr : 1fr（右侧更宽） |
| 右栏高度 | `calc(100vh - 110px)`，内部滚动 |
| 面板圆角/阴影 | 15px / 0 14px 34px #101c3b26（吸顶时加强） |

## 四、Tab 清单

| Tab | 内容 | 可用操作 |
|---|---|---|
| AI 总结 | 一句话概括、核心要点、术语、受众 | 生成总结 |
| **章节与字幕** | 章节 chip 行 + 按章分组的字幕 | 生成章节、补标点、运行 ASR |
| 知识点 | 知识点列表（带时间戳） | 生成知识点 |
| 说明 | 来源、媒体状态、内容范围 | — |

## 五、字幕数据的三种形态

| 形态 | 来源 | 说明 |
|---|---|---|
| 细粒度分段 | `transcript_segments` | 库内保存，用于精确定位与章节/知识点引用 |
| 段落 | 前端 `mergeCues()` | 逐句合并（间隔≤700ms、≤70字、≤20s、句末标点断开） |
| 分章分组 | 前端 `chapterGroups` | 按章节时间范围切分段落 |

繁简转换（OpenCC t2s）与标点恢复（LLM）在**入库前**完成，库内始终是简体带标点的文本。
